# ПДД РБ: по пунктам

Приложение для изучения Правил дорожного движения Республики Беларусь. Пункты Правил показаны по одному на чёрном экране: читаете, листаете касанием, возвращаетесь к нужному.

**Открыть в браузере или на iPhone:** https://artem-krotkov.github.io/pdd-study/ (в Safari: «Поделиться» - «На экран Домой»)

**Android (APK):** https://github.com/artem-krotkov/pdd-study/releases/latest

## Что умеет

- Пункт показан целиком, длинный делится по предложениям. У подпункта серым показан главный пункт.
- Номера пунктов в тексте - ссылки: касание открывает нужный пункт во всплывающем окне.
- Рисунки разметки показаны в пунктах, листы дорожных знаков открываются по ссылке у знака.
- Переход по номеру пункта, например 31.4.
- Прогресс: какие пункты изучены, история, сохранение в файл.
- Шрифт и размер букв на выбор. Работает без интернета.

## Текст

Правила дорожного движения Республики Беларусь (Указ Президента №551 от 28.11.2005) в редакции с учётом Указа №295 от 04.08.2025. Источник: etalonline.by. Приложение не заменяет официальный текст: сверяйтесь с действующей редакцией на pravo.by.

## Чего в приложении нет

Это не тренажёр экзаменационных билетов: тестов и штрафов нет, только текст Правил и приложений.
